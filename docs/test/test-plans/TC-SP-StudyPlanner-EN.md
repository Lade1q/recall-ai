## UC-05: Create new study plan (SP-01)

**Main Endpoint:** `POST /api/v1/plans`

**Environment:**

- Base URL: `http://localhost:3001/api/v1`
- Auth: JWT Bearer token — obtained from `POST /api/v1/auth/login`
- Mock AI: `USE_MOCK_AI=true` in server's `.env`
- DB: Separate Test DB — reset using `npm run test:seed` before each run
- Sample files: `sample_lecture.pdf` (~2MB), `large_file.pdf` (~15MB), `document.docx`
