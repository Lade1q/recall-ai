- **AI Hỏi kế tiếp:** `How does adding a sentinel element to an array optimize the execution of a sequential search compared to the standard linear search without a sentinel?`
- **User Trả lời:** `Adding a sentinel element optimizes the sequential search by eliminating the need to check whether the current index is within the array bounds during each iteration. In a standard linear search, the loop must perform two checks per iteration: one to see if the element matches the target, and another to ensure the index hasn't exceeded the array size. By replacing the last element with the target value (the sentinel), we guarantee the search will always find a match. This allows us to use a simpler while loop that only checks if the current element matches the target. Reducing the comparisons from two to one per iteration makes the algorithm run faster, especially for large arrays (for instance, up to 20% faster for n = 15,000).`
