## UC-05: Tạo kế hoạch ôn tập mới (SP-01)

**Endpoint chính:** `POST /api/v1/plans`

**Môi trường:**

- Base URL: `http://localhost:3001/api/v1`
- Auth: JWT Bearer token — lấy từ `POST /api/v1/auth/login`
- Mock AI: `USE_MOCK_AI=true` trong `.env` server

- File mẫu: `sample_lecture.pdf` (~2MB), `large_file.pdf` (~15MB), `document.docx`

| **Các bước thực hiện**   | 1. Gửi `POST /api/v1/plans` với `name = "Ôn thi Giải tích"`, `deadline = "2026-12-31"`, `file = large_file.pdf` (15MB)<br>2. Kiểm tra HTTP status và response body<br>3. | **Ghi chú**              | HTTP 400 (không phải 413) vì `errorHandler.ts` bắt `MulterError` và map thành 400. Bài test boundary cho file đúng 10MB vượt qua chứng tỏ logic code chặt chẽ (không bị lỗi off-by-one).                                                                              |
