### TC-SP-06-02: Thêm cạnh thủ công tạo cycle → bị reject ngay lập tức

| Trường                   | Nội dung                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Function / Feature**   | UC-06 — Luồng ngoại lệ [E1] (Student thêm cạnh tạo chu trình)                                                                                                                                                                                                                                                                                                     |
| **Mã TC**                | TC-SP-06-02                                                                                                                                                                                                                                                                                                                                                       |
| **Tiêu đề**              | Student thêm cạnh thủ công tạo chu trình → hệ thống reject ngay lập tức với cảnh báo                                                                                                                                                                                                                                                                              |
| **Mô tả**                | Khi Student cố thêm một cạnh mới trên UI đồ thị mà cạnh đó tạo thành chu trình (VD: kéo từ node B về node A khi đã có A→B), hệ thống phải phát hiện ngay lập tức và reject với cảnh báo: _"Không thể thêm quan hệ này - sẽ tạo ra chu trình"_. Không ảnh hưởng các cạnh khác.                                                                                     |
| **Loại kiểm thử**        | Functionality / Interface                                                                                                                                                                                                                                                                                                                                         |
| **Độ ưu tiên**           | High                                                                                                                                                                                                                                                                                                                                                              |
| **Điều kiện tiên quyết** | - Có plan với đồ thị gồm ít nhất 2 nodes (A→B đã tồn tại)<br>- Student đã đăng nhập<br>- Xác định API endpoint để thêm cạnh mới (VD: `POST /api/v1/study-plans/{planId}/edges`)                                                                                                                                                                                   |
| **Các bước thực hiện**   | 1. Lấy `planId` từ plan đang ở bước xem đồ thị<br>2. Gọi API thêm cạnh: thêm `B→A` (tạo cycle khi đã có `A→B`)<br>3. Kiểm tra HTTP status<br>4. Kiểm tra response body có cảnh báo<br>5. Kiểm tra DB: cạnh `B→A` **không được** thêm vào `concept_edges`                                                                                                          |
| **Dữ liệu đầu vào**      | Dữ liệu chung: `planId` _(có plan với cạnh: A→B)_<br>Bộ 2 sub-case:<br>• **02a** — Request thêm cạnh `B→A` (tạo chu trình 2 đỉnh)<br>• **02b** — Request thêm cạnh self-loop `A→A` (tạo chu trình 1 đỉnh)                                                                                                                                                         |
| **Kết quả mong đợi**     | - HTTP Status: **400 Bad Request** / **422 Unprocessable Entity**<br>- `"success": false`<br>- `error.code` = `"CYCLE_DETECTED"` hoặc `"WOULD_CREATE_CYCLE"`<br>- `error.message` = `"Không thể thêm quan hệ này - sẽ tạo ra chu trình"` (theo UC-06 [E1])<br>- DB `concept_edges`: cạnh mới **không được** lưu<br>- Các cạnh khác hiện có **không bị ảnh hưởng** |
| **Kết quả thực tế**      | _(điền sau khi test)_                                                                                                                                                                                                                                                                                                                                             |
| **Trạng thái**           | Not Run                                                                                                                                                                                                                                                                                                                                                           |
| **Ghi chú**              | Đã tích hợp test self-loop vào subcase 02b. Text cảnh báo trả về bắt buộc phải là: `"Không thể thêm quan hệ này - sẽ tạo ra chu trình"` (khớp UC-06 [E1]).                                                                                                                                                                                                        |

### TC-SP-06-03: API lưu đồ thị thưa (0 cạnh) thành công — Cảnh báo Traceback do Frontend xử lý

| Trường                   | Nội dung                                                                                                                                                                                                                                                                                                  |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Function / Feature**   | UC-06 — Luồng ngoại lệ [E2] (Student xóa toàn bộ quan hệ tiên quyết)                                                                                                                                                                                                                                      |
| **Mã TC**                | TC-SP-06-03                                                                                                                                                                                                                                                                                               |
| **Tiêu đề**              | Cập nhật đồ thị với mảng `edges` rỗng được Backend lưu thành công (Cảnh báo là nhiệm vụ của UI)                                                                                                                                                                                                           |
| **Mô tả**                | Khi Student xóa tất cả các cạnh (đồ thị thưa, không có quan hệ tiên quyết), Frontend sẽ bật popup cảnh báo. Nếu Student xác nhận "Vẫn tiếp tục", Frontend gọi API với `edges: []`. Backend API không trả warning mà chỉ lưu trực tiếp thành công.                                                         |
| **Loại kiểm thử**        | Functionality                                                                                                                                                                                                                                                                                             |
| **Độ ưu tiên**           | Medium                                                                                                                                                                                                                                                                                                    |
| **Điều kiện tiên quyết** | - Có plan với đồ thị có ít nhất 2 cạnh<br>- Student đã đăng nhập                                                                                                                                                                                                                                          |
| **Các bước thực hiện**   | 1. Lấy `planId` của một bản nháp đang có cạnh<br>2. Gửi request `PUT /api/v1/plans/{planId}/graph` với `edges: []` (giả lập việc Student đã bấm Xác nhận trên UI)<br>3. Kiểm tra HTTP status và response<br>4. Kiểm tra DB `concept_edges`                                                                |
| **Dữ liệu đầu vào**      | `planId`: _(plan ID hợp lệ)_<br>Request Body: `{ "concepts": [giữ nguyên], "edges": [] }`                                                                                                                                                                                                                 |
| **Kết quả mong đợi**     | - HTTP Status: **200 OK**<br>- `"success": true`<br>- Response trả về không kèm lỗi/cảnh báo nào<br>- DB `concept_edges`: **0 bản ghi** với `plan_id = planId`<br>- DB `concepts`: vẫn giữ nguyên (chỉ xóa edges)                                                                                         |
| **Kết quả thực tế**      | _(điền sau khi test)_                                                                                                                                                                                                                                                                                     |
| **Trạng thái**           | Not Run                                                                                                                                                                                                                                                                                                   |
| **Ghi chú**              | Cảnh báo hiển thị bắt buộc là: `"Không có quan hệ tiên quyết - tính năng Traceback sẽ không hoạt động. Vẫn tiếp tục?"` (khớp UC-06 [E2]). Tuy nhiên, Test Case này xác nhận việc hiển thị popup là **trách nhiệm của Frontend (E2E Test)**. Backend API chỉ làm nhiệm vụ lưu DB thành công khi mảng rỗng. |
