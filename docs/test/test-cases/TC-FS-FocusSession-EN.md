## Data Conventions and Environment

- The primary learner is logged in; has one active revision plan, one suggested concept, and one priority item in the review queue pointing to that concept. The other learner is an independent account.
- The test environment allows shortening a Pomodoro turn; the meaning must be equivalent to the default 25-minute configuration.
- Do not mock successful requests. Can inspect request, response, and DB to verify the contract.
- PASS/FAIL results reflect the Playwright run on 2026-08-10 on Chromium and Firefox; TC-FS-024 was re-verified as PASS on 2026-08-12 after fixing the short session cleanup regression.
- N/A cases in the exclusion table are scope decisions, not test execution results, and are not counted towards the PASS/FAIL metrics.
