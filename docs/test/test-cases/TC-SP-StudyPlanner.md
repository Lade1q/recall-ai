## SP-01: Tạo Kế hoạch Học tập (Create Study Plan)

**Endpoint chính:** `POST /api/v1/study-plans`  
**Endpoint danh sách:** `GET /api/v1/study-plans`

> **Luồng cơ bản (Basic Flow):**  
> Người dùng điền tên môn học, deadline, upload tài liệu → Hệ thống gửi lên AI Service → AI trả về JSON concepts + edges → Hệ thống validate DAG → Lưu DB → Hiển thị đồ thị cho người dùng xác nhận → SRE tạo lịch học.

## Ghi Chú Quan Trọng Về Môi Trường Test

> **AI Service Mocking:**  
> Vì AI Service (Gemini) trả về kết quả không xác định (non-deterministic), tất cả automated test **phải** dùng mock AI response cố định. Chỉ test manual mới nên gọi AI thật.

> **Database State:**  
> Mỗi test nên bắt đầu với DB state đã biết trước. Dùng `npm run test:seed` để reset DB về trạng thái chuẩn trước khi chạy test suite.

> **Test Execution Order:**  
> TC-SP-01-01 phải chạy trước TC-SP-01-08 vì TC-SP-01-08 phụ thuộc vào `planId` từ TC-SP-01-01. Các TC còn lại độc lập nhau.

> **DAG Verification Script:**  
> Với các TC liên quan đến DAG (TC-SP-01-07, TC-SP-01-17), dùng script kiểm tra bằng thuật toán Kahn's để verify đồ thị trong DB sau test:
>
> ```js
> // Kahn's algorithm — verify no cycle in stored edges
> function hasNoCycle(edges) {
>   const inDegree = {};
>   const adj = {};
>   for (const { from, to } of edges) {
>     adj[from] = adj[from] || [];
>     adj[from].push(to);
>     inDegree[to] = (inDegree[to] || 0) + 1;
>     inDegree[from] = inDegree[from] || 0;
>   }
>   const queue = Object.keys(inDegree).filter((n) => inDegree[n] === 0);
>   let visited = 0;
>   while (queue.length) {
>     const node = queue.shift();
>     visited++;
>     for (const neighbor of adj[node] || []) {
>       if (--inDegree[neighbor] === 0) queue.push(neighbor);
>     }
>   }
>   return visited === Object.keys(inDegree).length; // true = no cycle
> }
> ```
