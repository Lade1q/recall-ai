## UC-05: Tạo kế hoạch ôn tập mới

**Endpoint chính:** `POST /api/v1/study-plans`

> **Luồng cơ bản:**  
> Student nhập tên + deadline + upload tài liệu → Hệ thống ghi bản nháp `draft` vào DB + `analysis_jobs` → Gọi AI Service → AI trả JSON `{ concepts: [...] }` → Validate DAG → Lưu `concepts`/`concept_edges` → Plan chuyển `draft → active` → SRE tạo lịch học.

> TC-SP-05-01 phải chạy trước TC-SP-07-01. Các TC còn lại độc lập nhau.

> **DAG Verification Script (Kahn's Algorithm):**
>
> ```js
> // Dùng để verify không có cycle trong edges lưu trong DB
> function hasNoCycle(edges) {
>   const inDegree = {};
>   const adj = {};
>   for (const { from, to } of edges) {
>     adj[from] = adj[from] || [];
>     adj[from].push(to);
>     inDegree[to] = (inDegree[to] || 0) + 1;
>     inDegree[from] = inDegree[from] || 0;
>   }
>   const queue = Object.keys(inDegree).filter((n) => inDegree[n] === 0);
>   let visited = 0;
>   while (queue.length) {
>     const node = queue.shift();
>     visited++;
>     for (const neighbor of adj[node] || []) {
>       if (--inDegree[neighbor] === 0) queue.push(neighbor);
>     }
>   }
>   return visited === Object.keys(inDegree).length; // true = no cycle
> }
> ```
