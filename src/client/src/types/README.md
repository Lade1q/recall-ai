# Thư mục Types

Thư mục này chứa tất cả các định nghĩa kiểu dữ liệu (TypeScript Interfaces / Types) được sử dụng trong toàn bộ hệ thống Frontend.

## 💡 Vai trò chính

- Định nghĩa cấu trúc dữ liệu trả về từ API (ví dụ: `User`, `Task`, `Plan`).
- Định nghĩa kiểu cho các props truyền vào components.
- Đảm bảo tính chặt chẽ về mặt dữ liệu (type safety), giúp IDE gợi ý code tốt hơn và phát hiện lỗi sớm khi viết code.
